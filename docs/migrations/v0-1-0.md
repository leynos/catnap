# Build orchestration migration guide

This guide maps the former Make interface to the Netsuke build workflow. The
repository's [Netsukefile](../../Netsukefile) is the source of truth for action
names, commands, and dependencies.

## Command mapping

The table maps every named target in the former Makefile, including `typecheck`
and `help`, to its current Netsuke equivalent. The old pattern rule
`target/%/catnap` was an implementation detail used by `build` and `release`,
not a separate public target.

Table 1. Former Make targets and their Netsuke equivalents.

| Former Make target        | Netsuke command                         | Notes                                                                                     |
| ------------------------- | --------------------------------------- | ----------------------------------------------------------------------------------------- |
| `all`                     | `netsuke`                               | Runs `check-fmt`, `lint`, `test`, `spelling`, and `test-workflow-contracts` sequentially. |
| `actionlint`              | `netsuke build actionlint`              | Lints GitHub Actions workflows and their shell scripts.                                   |
| `build`                   | `netsuke build build`                   | Builds the debug `catnap` binary.                                                         |
| `check-build-tools`       | `netsuke build check-build-tools`       | Checks the pinned development toolchain and linker.                                       |
| `check-coverage-tools`    | `netsuke build check-coverage-tools`    | Checks the coverage toolchain and LLVM linkers.                                           |
| `check-fmt`               | `netsuke build check-fmt`               | Checks Rust and Markdown formatting.                                                      |
| `check-rust-toolchain`    | `netsuke build check-rust-toolchain`    | Checks the pinned Rust toolchain and components.                                          |
| `clean`                   | `netsuke build clean`                   | Runs `cargo clean`.                                                                       |
| `coverage`                | `netsuke build coverage`                | Writes `lcov.info`; configures `clang` and `lld` for coverage.                            |
| `fmt`                     | `netsuke build fmt`                     | Formats Rust and Markdown sources.                                                        |
| `github-actions-lint`     | `netsuke build github-actions-lint`     | Runs YAML and GitHub Actions workflow linting.                                            |
| `help`                    | `netsuke help targets`                  | Lists actions with their descriptions.                                                    |
| `install-build-tools`     | `netsuke build install-build-tools`     | Installs the pinned development toolchain and mold.                                       |
| `install-cranelift`       | `netsuke build install-cranelift`       | Installs Cranelift for the pinned nightly toolchain.                                      |
| `lint`                    | `netsuke build lint`                    | Runs Rust and GitHub Actions linting.                                                     |
| `markdownlint`            | `netsuke build markdownlint`            | Lints Markdown; its dependency runs the spelling checks first.                            |
| `nixie`                   | `netsuke build nixie`                   | Validates Mermaid diagrams.                                                               |
| `release`                 | `netsuke build release`                 | Builds the release `catnap` binary.                                                       |
| `spelling`                | `netsuke build spelling`                | Enforces the repository's spelling policy.                                                |
| `test`                    | `netsuke build test`                    | Uses nextest when available; otherwise uses `cargo test`.                                 |
| `test-ui`                 | `netsuke build test-ui`                 | Runs public error UI contract tests.                                                      |
| `test-workflow-contracts` | `netsuke build test-workflow-contracts` | Checks the shared CV-005 workflow contracts.                                              |
| `typecheck`               | `netsuke build typecheck`               | Runs Cargo check across all targets and features.                                         |
| `yamllint`                | `netsuke build yamllint`                | Lints every tracked YAML file strictly.                                                   |

## Test and doctest behaviour

The test action uses `cargo nextest run --all-targets --all-features` when
`cargo-nextest` is available, then runs workspace doctests with
`cargo test --workspace --doc --all-features`. When cargo-nextest is
unavailable, it runs `cargo test --all-targets --all-features`, which does not
run workspace doctests.

## Installation and compatibility

There is no Make compatibility shim. Install the pinned Netsuke release using
the nightly toolchain declared by CI, and install Ninja because Netsuke uses it
to execute the generated build graph. On Linux, install `clang`, `lld`, and
`mold` for building and coverage workflows, alongside Ninja. The Netsuke
installation command is:

```sh
rustup toolchain install nightly-2026-08-23
cargo +nightly-2026-08-23 install --locked netsuke-build \
  --version =0.1.0-beta4
```

Netsuke beta4 is pinned in CI. The workflow caches the installed executable by
version, runner operating system and architecture, and installation toolchain.
For the complete local tool list and workflow details, see the
[developer guide](../developers-guide.md).
